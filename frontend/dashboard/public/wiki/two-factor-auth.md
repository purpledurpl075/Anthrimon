# Two-Factor Authentication (TOTP)

Optional, per-user — not enforced platform-wide. Each user decides whether to turn it on for their own account.

## Enabling 2FA

1. Go to your **Account** page → **Security** section
2. Start 2FA setup — a QR code appears
3. Scan it with an authenticator app (Google Authenticator, Authy, 1Password, etc.)
4. Enter the 6-digit code it generates to confirm
5. You'll be shown a set of one-time-use **backup codes** — save these somewhere safe. Use one to log in if you lose access to your authenticator app.

Once enabled, logging in requires your password plus a code from your authenticator app (or a backup code).

## Regenerating backup codes or disabling 2FA

Both are available from the same **Account** → **Security** section, and both require entering a current code from your authenticator app to confirm.
